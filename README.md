# AI Resume Analyzer

A simple **AI Resume Analyzer** website built using HTML, CSS and JavaScript.

## Features

* Resume upload
* Resume analysis
* Skill detection
* Keyword analysis
* ATS-style score
* Missing keywords
* Resume improvement suggestions
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/itsarnav2112-kas/AI-RESUME-ANALYZER.git
```

2. Open the project folder.
3. Open `index.html` in your browser.
